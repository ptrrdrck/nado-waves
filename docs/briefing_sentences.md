# Briefing: every sentence it can say, for editing

Generated by `python -m forecast.briefingwording` from the page's own code
(`app/forecast.html`), run on the made-up issues listed at the end, so each
line is exactly what the page prints. Every distinct sentence appears once,
in the order the page says it, under its entry; the cases it appears in
follow it in brackets. The numbers are made up; only the wording is under
review.

**To edit**: change the sentence in place, or add a line beneath it starting
`>>` with a note. Commit the file on a branch; the edits are carried into
the page by hand and this file regenerated, so a sentence edited here and
not in the page will read as the page's again until that happens. A slot
with no value drops with its joining words; the formula is in
`docs/briefing_wording.md`.
